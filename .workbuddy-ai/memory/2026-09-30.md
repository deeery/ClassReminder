### ★ 踩坑（务必记住）
**kapt 把 KDoc 转成 Java stub 时，注释里的 `\uXXXX`（带反斜杠）会被 javac 当成 Unicode 转义解析**，
报「非法的 Unicode 转义」，而且报错指向 `app/build/tmp/kapt3/stubs/...` 下的生成文件、不是源码，
第一次看很容易懵。→ KDoc 里提 unicode 转义要写成 `U+XXXX`。

### 6. 问候语：34sp SemiBold → 38sp Light（v4.3.1 追加）
- 字号 34 → **38sp**（Material 的 displaySmall 是 36sp，刻意压过一格），行高 42 → 46sp
- 字重 SemiBold → **Light**（用户要求「细字体」；38sp 已靠字号撑气势，加粗显笨重）
- **40sp 是上限**：「早上好。」在 360dp 窄屏会折行
- 实测：文字高 86px → **96px**（+12%），笔画墨量 **−25%**（Light 生效，未回退 Regular）
