周课表网格 — 表格视觉优化验收

这是把 Compose 里 WeekGrid 的渲染逻辑用 HTML/CSS 复刻的验收稿，参数与源码常量一一对应。 你可以在浏览器里逐项对照、切换深浅主题、模拟窄屏，确认满意后再落地到 APK。

鼠标在课程块上移动可以看到整列轻高亮（表头也会跟着亮）；把鼠标移到星期表头上可以点击选中该列，看选中态与今日下划线。

表格课程块交互

单击 = 高亮 / 双击 = 编辑

表格界面（WeekGrid 里的 GridCell）。 第一次点下就立即高亮（onPress → onSelect）， 不管是准备单击还是双击 —— 不等双击判定窗口，手感不木。 单击只高亮、不进编辑；双击才进编辑；点空白处取消选中。 选中时左侧色条加粗到 4px 并按「是否今天」分流： 今日选中 = 蓝（primary），非今日选中 = 灰 （深色 surfaceVariant / 浅色 outlineVariant）。

按下任意课程块（当帧就高亮：色条加粗 + 描边 + 光晕 + 放大 5%）、 双击同一个块（底部弹出「进入编辑」提示）、点网格空白处（取消选中）。 每周二有课、周五有课，注意对比周二（今日·蓝）与周五（非今日·灰）被选中时的色条差别。

非今日选中 · 灰条（同宽度，仅换色）

高亮列修复

fill / color / no-stray-bar

本次针对截图中三个问题的修复。1) 高亮底色原来每列留 1px 内边距，铺不满、列间露背景 → 形成黑色断层，现在铺满整列、列与列严丝合缝； 2) 今日列与非今日列原来共用主色、只差透明度 → 无法区分， 现在今日=蓝、非今日=灰，两套颜色； 3) 表头每列各自圆角 → 列间切出缺口，且左侧刻度占位与列身衔接断裂 → 看起来像 伸出一根多余竖条，现在表头只保留最外侧圆角、连成一条。

↑ 补充修复：表头原来在 Row 上挂了 padding-bottom: 6px， 这一段没有底色 → 表头底与列身顶之间夹出一条透明横带，高亮列被切成「上深下浅」两截。 现已把间距移进格子内部（HEADER_GAP），底色全程铺满。

默认已手动高亮 周四（灰 · 非今日），而 周二 是今天（蓝 · 常态弱底）。 注意对比：周四的灰色整列铺满无缝隙，周二的蓝色弱底始终可见，「今日」角标贴在周二上。 点击任意表头可切换高亮列。

斑马纹：按小时交替的时间带

ZEBRA_ALPHA = 0.03

网格是按时间轴定位的，没有网页表格那种「行」，但时间本身就是行——一小时一行。 按偶/奇小时交替铺一层 α 0.03 的底纹，眼睛扫行时有了参照物。 刻意比横向时刻线（0.08）还淡：它是「背景的背景」，一旦看得出来就会盖过课程块。

悬停整列 · 点击选中 · 今日标识

hover / active / today

三档强度严格分级：悬停（浅色 α0.022 / 深色 0.05，最弱，只是「预告」）→ 选中（浅色 0.055 / 深色 0.14，加左右各 1px 主色描边）→ 今日（独立的下划线 + 角标， 与选中可以并存）。悬停某个课程块时，整列连同表头一起亮——查的是「这一列有什么课」， 不是「这个格子有什么课」。

试着把鼠标移进任意一个课程块：整列会亮起，表头文字同时加深。再点表头「周四」选中它，对比两档强度差别。

窄屏响应式

COMPACT_BREAKPOINT = 360dp

窄于 360dp 时整套尺寸降一档：时间栏从 38dp → 30dp、 今日列加宽系数从 1.35 → 1.15、字号统一乘 0.92。 下面是 360px 宽度下的实际效果。
